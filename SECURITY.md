# Security Policy

rReadNote reads and writes user-selected Markdown workspaces, including notes, reading state, and highlights. Do not include personal notes, private libraries, screenshots, complete machine paths, tokens, or other user content in public issues, pull requests, or fixtures.

If a secret or private document is exposed, remove public copies where possible, revoke or rotate any credential, then report the incident privately through GitHub's **Security > Report a vulnerability** flow. Include the affected commit or version, reproduction conditions, and impact without publishing sensitive content.

The `0.1.x` line is a development preview. Release packages may be unsigned or unnotarized; see [RELEASE.md](RELEASE.md).
