# Public Repository Boundary

This repository is intended to be public source code for rReadNote. It contains application source, documentation, tests, manifests, and synthetic examples only.

User Markdown, reading state, highlights, screenshots, personal paths, tokens, and other private content must stay outside the repository. The committed demo book is synthetic product content used to exercise the reader UI; it is not a user's library.

The application reads and writes local files and `.rreadnote/` metadata in a user-selected workspace. Publishing this repository does not publish that workspace. If sensitive data is found, report it privately as described in [SECURITY.md](SECURITY.md).
